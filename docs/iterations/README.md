# Smart Velp Iterations

This directory stores product requirements and iteration notes for Smart Velp.

## Directory Convention

Each iteration should use a numbered folder:

```text
docs/iterations/
  001-local-first-content-pack-mvp/
    PRD.md
    TASKS.md
    DECISIONS.md
  002-content-catalog-download/
    PRD.md
    TASKS.md
    DECISIONS.md
```

## File Roles

- `PRD.md`: product requirements, scope, user flows, functional requirements, and acceptance criteria.
- `TASKS.md`: engineering tasks split by frontend, backend/local storage, content, testing, and release.
- `DECISIONS.md`: important product or technical decisions made during the iteration.
